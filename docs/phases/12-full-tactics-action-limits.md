# Phase 12 — Full Tactics & Action Limits

**Depends on:** 11
**Complexity:** M

## Goal
The complete live-tactics toolkit from the original design vision.

## Tasks
- [ ] Formation change UI + server-side application with the same delayed-application pattern as subs
- [ ] Full mentality range (beyond the MVP defensive/balanced/attacking three-state)
- [ ] Tactical-change action counter (3-4/half) enforced server-side

## Explicitly out of scope

A manager can meaningfully alter a losing match's trajectory through committed live decisions; rapid spam-changing is empirically a worse strategy in test matches.
