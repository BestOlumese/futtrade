# Phase 26 — Trader Role

**Depends on:** 16, 25
**Complexity:** M

## Goal
The full two-sided-economy vision — a user who never touches tactics can meaningfully participate.

## Tasks
- [ ] Trader account type/onboarding path (separate from manager onboarding)
- [ ] Market UI confirmed to work identically for trader and manager accounts, no tactics-panel leakage
- [ ] Spectator access to live matches without tactics controls, per the spectator view in `docs/08-live-match-viewer.md`

## Explicitly out of scope
- Trader-specific gamification beyond the leaderboard already built in Phase 25

## Exit criteria
A trader-only account can watch a live match, react to it by trading, and appear correctly on the Top Traders leaderboard — with zero access to any manager-only controls.
